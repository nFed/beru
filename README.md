# ליו הפקות

אתר עמוד אחד לליו הפקות, מבית היוצר של שמואל ברו.

| קובץ / תיקייה | מה יש בו |
|---|---|
| `index.html` | כל האתר: HTML, CSS ו-JavaScript, בלי תלויות בנייה |
| `logo.svg` | הלוגו (צללית); משמש בתפריט, בפתיח, בפוטר וכ-favicon |
| `stills/` | פריימים מההפקות (ראו `stills/README.md`) |
| `img/` | תמונות נוספות (תמונת הפרופיל של שמואל) |
| `og-image.jpg` | התמונה שמופיעה בשיתוף קישור ברשתות |
| `apple-touch-icon.png` | אייקון לשמירת האתר במסך הבית באייפון |

## עדכונים שגרתיים

- **לוח אירועים:** הרשימה `EVENTS` בתחילת הסקריפט בתחתית `index.html`. אירועים שהתאריך שלהם עבר נעלמים לבד. לכל אירוע: תאריך, שעה, סוג, כותרת, מקום ועיר. הפרטים מוצגים בחלון קטן בלחיצה על האירוע.
- **מעבר לדומיין:** לעדכן את כל השורות המסומנות ★ ב-`<head>` (קישורים, תמונת שיתוף ונתונים מובנים).

## Leeu Production — האתר החדש (בעבודה)

הגרסה הנבחרת נמצאת ב-`site/` ועולה בכתובת `/site/`. האתר הישן שבשורש עדיין לא הוחלף.

| קובץ / תיקייה | מה יש בו |
|---|---|
| `site/index.html` | מבנה העמוד והטקסטים |
| `site/assets/css/style.css` | העיצוב |
| `site/assets/js/main.js` | התנועה: התפריט, הגלריה במובייל, קוד הזמן, הופעת הקטעים |
| `site/assets/img/` | תמונות WebP בשני גדלים כל אחת (הדפדפן בוחר לפי המסך), והלוגו `mark.svg` |
| `sketches/archive/` | כל הסקיצות הקודמות ועמוד המפה שלהן, עם התמונות שלהן |

**החלפת תמונה בגלריה:** לשמור שתי גרסאות WebP ברוחב 700 ו-1200 פיקסלים בשם `work-N-700.webp` ו-`work-N-1200.webp`; לתמונות שמוצגות במובייל בחיתוך אחר (גבוה או ריבועי) גם `work-N-m-480.webp` ו-`work-N-m-720.webp`.
