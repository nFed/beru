# Leeu Productions

אתר עמוד אחד של Leeu Productions, חברת הפקות וידאו מתל אביב. קבצים סטטיים בלבד, בלי שלב בנייה. GitHub Pages מפרסם את ענף `main`.

| קובץ / תיקייה | מה יש בו |
|---|---|
| `index.html` | האתר בעברית (ברירת המחדל): מבנה העמוד והטקסטים |
| `en/index.html` | האתר באנגלית, משמאל לימין. כל שינוי תוכן נעשה בשני הקבצים |
| `assets/css/style.css` | העיצוב |
| `assets/js/main.js` | התנועה: התפריט, הגלריה במובייל, קוד הזמן, הופעת הקטעים |
| `assets/img/` | תמונות WebP בשני גדלים כל אחת (הדפדפן בוחר לפי המסך), הלוגו `mark.svg`, תמונת השיתוף `og-image.jpg` ואייקון האייפון |
| `404.html` | דף ״לא נמצא״; מעביר קישורים ישנים (`/site/`, `/sketches/…`) למקום החדש |
| `archive/sketches/` | כל הסקיצות שקדמו לאתר הזה ועמוד המפה שלהן |
| `archive/logo-sketches/` | סקיצות הלוגו, הפתיח והגופנים (עם עותק קפוא של העיצוב) |

הדפים בארכיון מסומנים כך שמנועי חיפוש לא יאנדקסו אותם.

## עדכונים שגרתיים

- **החלפת תמונה בגלריה:** לשמור שתי גרסאות WebP ברוחב 700 ו-1200 פיקסלים בשם `work-N-700.webp` ו-`work-N-1200.webp`; לתמונות שמוצגות במובייל בחיתוך אחר (גבוה או ריבועי) גם `work-N-m-480.webp` ו-`work-N-m-720.webp`.
- **מעבר לדומיין:** לעדכן את השורות המסומנות ★ ב-`<head>` של `index.html` ושל `en/index.html` (כתובות האתר, הקישורים בין השפות ותמונת השיתוף).
